Pelatihan Version Control System dengan Git & GitHub

Pelajari bagaimana Version Control System membantu menyimpan riwayat perubahan, mengelola source code, dan memudahkan kolaborasi dalam pengembangan perangkat lunak.

Mulai Belajar Lihat Praktik

$ git init

$ git add .

$ git commit -m "Initial commit"

$ git push -u origin main

✓ Project berhasil disimpan
PROBLEM STATEMENT

Kenapa kita membutuhkan Version Control?

Dalam kerja kelompok coding, pengelolaan file secara manual dapat menimbulkan berbagai masalah.

01

File Bertumpuk

website-final.zip website-final-fix.zip website-final-fix2.zip website-final-baru.zip

Sulit mengetahui file mana yang merupakan versi terbaru.

02

Perubahan Tidak Terlacak

  • File tertimpa
  • Edit bersamaan
  • Tidak tahu siapa mengubah apa
03

Kolaborasi Sulit

Penggunaan folder biasa atau pengiriman file membuat proses kerja kelompok menjadi kurang terorganisir.

Tanpa Version Control

✕ Tidak ada histori ✕ Tidak tahu perubahan ✕ Sulit kolaborasi ✕ Takut kehilangan file
SOLUTION

Apa itu Version Control System?

VCS adalah sistem yang digunakan untuk mencatat setiap perubahan pada proyek atau source code dari waktu ke waktu.

VCS

Dengan Version Control System, pengembang dapat mengetahui perubahan yang terjadi pada sebuah project dan mengelola berbagai versi project dengan lebih teratur.

01

Melihat Perubahan

Mengetahui siapa yang melakukan perubahan.

02

Riwayat Project

Mengetahui kapan perubahan dilakukan.

03

Membandingkan Versi

Membandingkan perubahan antar versi project.

04

Restore

Mengembalikan project ke versi sebelumnya.

Tanpa Version Control

  • File bertumpuk
  • Sulit kerja kelompok
  • Tidak tahu siapa yang mengubah
  • Sulit kembali ke versi lama
VS

Dengan Version Control

  • Semua perubahan tercatat
  • Bisa melihat riwayat project
  • Bisa kembali ke versi sebelumnya
  • Banyak orang dapat bekerja bersama
  • Project lebih aman dan terorganisir

HANDS-ON PRACTICE

Praktik Dasar Git

Ikuti langkah berikut untuk membuat project sederhana dan mulai menggunakan Git.

01

Buat Folder Project

Buat folder project dengan nama sesuai kebutuhan.

project-git ├── index.html └── style.css
02

Inisialisasi Git

Buka Git Bash pada folder project kemudian jalankan:

git init
Perintah ini membuat repository Git pada project.
03

Cek Status

Gunakan git status untuk melihat kondisi project.

git status
04

Masukkan File ke Staging

Masukkan perubahan ke staging area.

git add .
05

Buat Commit

Simpan snapshot project ke dalam histori Git.

git commit -m "Initial commit"
06

Lihat History

Lihat seluruh commit yang sudah dibuat.

git log
07

Restore File

Mengembalikan file ke kondisi pada commit tertentu.

git restore --source=<commit-id> index.html

Ringkasan Command Git & GitHub

Command Fungsi
